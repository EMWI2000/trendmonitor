Consequences for the pipeline:

1. Explicit `currency` per brand and `fx_to_dkk` in sources.yaml; `price_dkk` on every row.
2. `live_days` filter: keep a product only if ≥ 1 variant is available or it was published within
   120 days; otherwise outlet archives (Munthe, Herskind) dominate every metric.
3. Size detection accepts UK/EU prefixes and size in any option; colour-in-option1 stores work.
4. `exclude_types` / `exclude_tags` per brand for beauty, home, knitting patterns, men's, accessories.
5. `season_tag` extracted from tags (SS27, FW26, PS25, PF25, "SEASON - 264", "27 Pre Spring").
6. Structured brand tags (Stine Goya `print:Florals`, Munthe `SYSCOL - Brown`) already match the rule
   tagger's keywords; a per-brand tag parser can tighten this later.
